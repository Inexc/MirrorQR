# 📱 TranSlipt — Экран по QR

> Быстрая беспроводная трансляция экрана компьютера на телефон по локальной сети через **WebRTC** — без установки сторонних приложений на мобильное устройство, с интерактивным масштабированием и удалённым управлением мышью.

---

## ⚡ Возможности

* 🚀 **GPU-ускоренный захват экрана:**
  * Прямой захват кадров рабочего стола через **dxcam** (DirectX 11 / DXGI Desktop Duplication) с аппаратным ускорением.
  * Надёжный fallback на **mss** (GDI/BitBlt).
  * Минимальная задержка передачи по LAN (< 50 мс) и высокий битрейт (до 12 Мбит/с) без артефактов компрессии.
* 🖥️ **Поддержка нескольких мониторов:**
  * Автоматическое определение подключённых дисплеев и их разрешения.
  * Выбор транслируемого монитора прямо в панели управления или окне приложения.
* 📱 **Никаких приложений на телефоне:**
  * Работает в любом современном мобильном браузере (**Safari** на iOS, **Chrome**, **Firefox**, **Samsung Internet** на Android).
  * Быстрое подключение сканированием QR-кода стандартной камерой телефона.
* 🔍 **Интерактивное масштабирование (Pinch-to-zoom & Pan):**
  * Масштабирование щипком двумя пальцами от **1.0x** до **4.5x**.
  * Перемещение (панорамирование) одним пальцем по увеличенному экрану без вылета за границы.
  * Быстрый сброс или приближение двойным тапом.
  * Кнопка сброса масштаба `1.0x ↺` в верхней панели.
* 🖱️ **Удалённое управление мышью (Touchpad Mode):**
  * **Тап** — клик левой кнопкой мыши (ЛКМ) в точные координаты рабочего стола.
  * **Двойной тап** — двойной клик (2x ЛКМ) для открытия файлов и папок.
  * **Удержание пальца (450 мс)** — правый клик (ПКМ, вызов контекстного меню) с лёгким виброоткликом.
  * **Движение пальца** — плавное ведение курсора мыши (синхронизировано через `requestAnimationFrame`).
  * **Свайп двумя пальцами** — прокрутка документов и страниц (колёсико мыши).
  * **Нижняя панель управления** — быстрые кнопки `[ПКМ]`, `[2x ЛКМ]`, `[▲ Скролл]`, `[▼ Скролл]`.
* 📺 **Полноэкранный режим и масштабирование:**
  * Настоящий Fullscreen API на Android и `webkitEnterFullscreen` на iOS.
  * Переключение режима отображения: «По размеру» (*contain* с сохранением пропорций) или «Заполнить» (*cover* на весь экран телефона).
* 🔋 **Защита сессии в фоне:**
  * **Screen Wake Lock API:** экран телефона не уходит в спящий режим во время просмотра.
  * **Keepalive Ping/Pong:** фоновые проверки соединения каждые 10 секунд предотвращают разрыв сессии роутером или браузером.
  * Автоматическое возобновление воспроизведения при переключении между приложениями/вкладками.
* 🔒 **Безопасность в локальной сети:**
  * Сессии защищены криптографическими одноразовыми токенами с ограниченным сроком действия (TTL).
  * Строго один активный клиент на сессию: попытки повторного входа отклоняются без сброса текущего просмотра.
* 🎛️ **Два режима работы на ПК:**
  * **Веб-панель (`--web`)** — лёгкий режим с локальной веб-страницей управления (`http://127.0.0.1:8766/desktop`), не требующий Qt.
  * **GUI-приложение** — классическое окно на PySide6 со сворачиванием в системный трей.

## 🚀 Быстрый старт

### Требования
* **ОС:** Windows 10 / 11 (или Linux)
* **Python:** CPython **3.13** (или 3.11+)
* Компьютер и телефон должны быть подключены к **одной локальной сети** (одному Wi-Fi роутеру).

### 1. Установка

Клонируйте репозиторий и установите зависимости:

```bash
git clone https://github.com/Inexc/TranSlipt.git
cd TranSlipt

# Создание виртуального окружения (Python 3.13)
py -3.13 -m venv .venv
.venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Запуск

Вы можете запустить проект в одном из двух режимов:

#### Вариант А: Режим веб-панели (Рекомендуемый)
Дважды кликните по файлу **`start-web.bat`** или выполните в консоли:
```bash
python main.py --web
```
Браузер автоматически откроет локальную панель: `http://127.0.0.1:8766/desktop`.

#### Вариант Б: Режим графического окна (Qt)
Дважды кликните по файлу **`start-gui.bat`** или выполните:
```bash
python main.py
```

### 3. Подключение телефона
1. В интерфейсе выберите ваш **локальный IP-адрес** (например, `192.168.x.x`) и нужный **монитор**.
2. Нажмите кнопку **«Запустить трансляцию»**.
3. Наведите камеру телефона на появившийся **QR-код** (или скопируйте ссылку).
4. В открывшемся браузере телефона начнётся трансляция рабочего стола!

## 📱 Жесты управления на телефоне

| Действие | Жест / Кнопка | Описание |
| :--- | :--- | :--- |
| **Клик (ЛКМ)** | Одиночное касание | Кликает в точку на экране ПК |
| **Двойной клик** | Быстрый двойной тап | Двойной щелчок (открыть папку/приложение) |
| **Правый клик (ПКМ)** | Удержание пальца (~0.5 сек) | Вызывает контекстное меню (с вибрацией) |
| **Перемещение курсора** | Ведение пальцем по экрану | Курсор ПК следует за пальцем в реальном времени |
| **Прокрутка (Колёсико)** | Свайп двумя пальцами вверх/вниз | Прокручивает страницу или документ |
| **Масштабирование** | Щипок двумя пальцами | Увеличение от 1.0x до 4.5x для мелкого текста |
| **Сброс зума** | Кнопка `1.0x ↺` или двойной тап | Возвращает исходный 100% масштаб |
| **Режим мыши** | Кнопка «Мышь» в верхней панели | Включает/выключает режим управления курсором |
| **Быстрые кнопки** | Нижняя плавающая панель | Кнопки `[ПКМ]`, `[2x ЛКМ]`, `[▲ Скролл]`, `[▼ Скролл]` |
| **На весь экран** | Кнопка «На весь экран» | Разворачивает плеер без рамок браузера |
| **По размеру / Заполнить**| Кнопка «Заполнить» | Переключает пропорции экрана (`contain` / `cover`) |

## 📁 Структура проекта

```text
TranSlipt/
├── main.py                  # Единая точка входа (--web или Qt GUI)
├── start-web.bat            # Быстрый запуск веб-панели в один клик
├── start-gui.bat            # Быстрый запуск Qt-окна в один клик
├── requirements.txt         # Зависимости проекта
├── README.md                # Документация
│
├── src/
│   ├── backend/             # Серверная логика и WebRTC
│   │   ├── service.py       # Координатор жизненного цикла сервиса
│   │   ├── session.py       # Менеджер сессий и одноразовых токенов
│   │   ├── signaling.py     # WebSocket-сигналинг и WebRTC peer connection
│   │   ├── web_panel.py     # Локальный веб-сервер панели управления (порт 8766)
│   │   └── remote_input.py  # Обработка удалённого ввода мыши и скролла (Win32)
│   │
│   ├── capture/             # Модули захвата видео
│   │   ├── factory.py       # Выбор источника видео под текущую ОС
│   │   ├── windows.py       # Захват Windows через dxcam (GPU) + mss (CPU)
│   │   ├── linux.py         # Захват Linux через PipeWire / Portal
│   │   └── portal.py        # Вспомогательные функции DBus Portal
│   │
│   ├── desktop/             # Десктопный GUI на PySide6
│   │   ├── window.py        # Главное окно с выбором IP и монитора
│   │   ├── tray.py          # Иконка и меню в системном трее
│   │   └── qr.py            # Отрисовка QR-кода
│   │
│   └── integration/         # Интеграционные тесты и проверки
│       ├── check_python_compat.py   # Проверка окружения и версий
│       ├── check_python_contract.py # Проверка контрактов запуска
│       ├── check_web_panel.py       # Тесты API веб-панели
│       ├── check_panel_lifecycle.py # Тесты жизненного цикла сервиса
│       └── check_runtime.py         # Сквозные тесты WebRTC и захвата
│
└── web/                     # Клиентская часть (HTML/CSS/JS)
    ├── desktop.html         # Страница веб-панели управления
    ├── desktop.css          # Стили панели управления
    ├── desktop.js           # Логика панели управления
    ├── phone.html           # Мобильный плеер трансляции
    ├── phone.css            # Мобильные стили (dark mode, адаптивность)
    └── phone.js             # WebRTC-клиент, зум, сенсорное управление мышью
```

## 🧪 Тестирование и самопроверка

В репозитории предусмотрен набор автоматических проверок:

```bash
# 1. Проверка версий библиотек и окружения
python src/integration/check_python_compat.py

# 2. Проверка контрактов аргументов командной строки
python src/integration/check_python_contract.py

# 3. Тестирование логики сессий и токенов
python src/backend/_selfcheck.py

# 4. Тестирование API локальной панели управления
python src/integration/check_web_panel.py

# 5. Тестирование жизненного цикла и освобождения портов
python src/integration/check_panel_lifecycle.py

# 6. Сквозная проверка WebRTC-сигналинга и фабрики захвата
python src/integration/check_runtime.py
```
