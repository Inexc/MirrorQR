Это зеркалирование экрана в браузере телефона, а не виртуальный монитор. Если захват экрана в Windows недоступен, перенос QR-кода на другой компьютер этого не исправит: проблему нужно решать на самом компьютере.

Страница открыта не через сервер

Панель работает только через локальный сервер. Запустите в папке проекта: 

python main.py --web

Затем откройте в браузере http://127.0.0.1:8766/desktop. Файл, открытый напрямую из проводника, не может загрузить оформление, скрипт и данные — серверные маршруты работают только на локальном порту.
